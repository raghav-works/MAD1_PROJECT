# MAD1_PROJECT
🎯 Quiz Master - V1 🧠💻
🚀 Overview

Quiz Master V1 is a Full-Stack Web Application built as part of the Mobile Application Development I (MAD I) course. It provides a smart and simple platform for learning through quizzes, with role-based access for Admins and Users.

👑 Admin (Quiz Master) can create and manage subjects, chapters, quizzes, and questions.

🙋‍♂️ Users can register, select subjects & chapters, attempt quizzes, and track their performance.

📊 All attempts are stored with scores and history for easy review.

🧰 Tech Stack & Tools

 • Backend: Flask (Python)

 • Frontend: Jinja2, HTML, CSS, Bootstrap

 • Database: SQLite (programmatically created, no external tools required)

 • Visualization: Matplotlib

 • Validation: Both Front-End & Back-End

🔐 Core Features

👨‍💼 Role-Based Access: Separate flows for Admin & Users.

🗂️ Hierarchy: Subjects → Chapters → Quizzes → Questions.

📅 Admin Control: Set quiz date, duration, remarks, and manage questions.

📝 Quizzes: Multiple-choice questions (single correct answer).

⏱️ Timer Support: Time-bound quizzes (optional).

📈 Score Dashboard: Track attempt history and performance.

🔍 Search & Management: Easy quiz/subject handling for Admins.
